# 🛒 Zepto Inventory & Pricing Analysis Dashboard

An interactive Power BI dashboard analyzing product inventory, pricing, 
and discount trends across categories for a quick-commerce grocery 
platform (Zepto-style dataset).

## 📊 Overview

This project explores how discounting strategy, stock availability, 
and category performance interact — helping identify which categories 
are over-discounted, which products are frequently out of stock, and 
where revenue is concentrated.

## ✨ Key Features

- **KPI Summary Cards** — Total Revenue, Average Discount %, Available 
  Quantity, and Out-of-Stock Count at a glance
- **Category-wise Discount Analysis** — horizontal bar chart showing 
  average discount % across product categories
- **Stock Status Breakdown** — donut chart visualizing in-stock vs 
  out-of-stock proportion
- **Top 5 Categories by Revenue** — ranked bar chart highlighting 
  top revenue-generating categories
- **Discount vs Quantity Scatter Plot** — bubble chart (sized by revenue) 
  revealing correlation between discount depth and stock movement
- **Interactive Product Table** — sortable, filterable product-level 
  detail view
- **Category & Stock Slicers** — dynamic filtering across the entire 
  dashboard

## 🛠️ Tools & Skills Used

- **Power BI Desktop** — data modeling, DAX measures, visual design
- **DAX** — custom calculated measures (Average Discount %, Revenue 
  Aggregation, Conditional Counts)
- **Data Cleaning** — handling multi-category product mapping, 
  aggregation correction (sum vs. average logic)
- **Dashboard UX/UI** — custom purple color theme, consistent card 
  styling, aligned layout

## 📈 Key Insights

- Identified categories with disproportionately high average discounts, 
  flagging potential margin risk
- Quantified out-of-stock rate (~12%) across the catalog, highlighting 
  inventory gaps
- Surfaced top revenue-driving categories to inform stocking priorities


## 🚀 How to Use

1. Clone/download this repo
2. Open `zepto_dashboard.pbix` in Power BI Desktop
3. Explore via slicers and cross-filtering on any visual
